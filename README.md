# Tallkeep for Windows

Installers for [Tallkeep](https://tallkeep.com). Tallkeep on your office computer updates itself
from here; you don't need to download anything by hand.

Newest version: **0.26.36**. Round 5: cancel blocked when paid (Undo cancel), Turn into an invoice posts it, deposits to Customer Deposits, tax over 50% stopped, equal vendor credit pays a bill, unsaved document changes kept across tabs, Overview Needs attention, Reports month-end list, new product with opening stock

Running Tallkeep on a Synology, a Linux server or anything with Docker: see [docker/README.md](docker/README.md).
