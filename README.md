# Tallkeep for Windows

Installers for [Tallkeep](https://tallkeep.com). Tallkeep on your office computer updates itself
from here; you don't need to download anything by hand.

Newest version: **0.26.37**. Round 6: take a deposit on a quote or order, partly fulfilled invoices keep stock value right, Who owes us explains the Balance Sheet gap, overdue link opens Past due, before-books note while picking the date, Pay Bills stays put for credit-only, Needs attention stacks on phones

Running Tallkeep on a Synology, a Linux server or anything with Docker: see [docker/README.md](docker/README.md).
